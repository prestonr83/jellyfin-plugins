Database maintenance

These operations are only available when PostgreSQL is active. Each one asks for confirmation and reports the result with a notification.

VACUUM ANALYZE

Reclaims dead tuple space and updates query planner statistics. Takes seconds and does not block reads.

REINDEX DATABASE

Rebuilds all indexes. May take several minutes and block writes while running.

Performance optimization

Creates GIN trigram indexes (pg_trgm) for instant search and tunes autovacuum on critical tables. Idempotent — safe to run multiple times.
